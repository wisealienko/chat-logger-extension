# Chat Logger

Расширение для Chrome: одним кликом сохраняет чат с Claude (claude.ai) или сессию Claude Code в Markdown — вместе со всеми файлами, артефактами и диаграммами. Логи удобно читать в Obsidian.

*Chrome extension: one-click export of claude.ai chats and Claude Code sessions to Markdown with all files, artifacts and diagrams.*

## Что получается

```
Downloads/ChatLogs/<Название чата>/
  <Название чата>.md     ← весь чат
  materials/             ← файлы, артефакты, диаграммы, скриншоты
    versions/            ← версии рабочих файлов, которые Claude создавал и правил
```

## Возможности

**Текст и структура**
- Диалог берётся целиком через внутренний API claude.ai — без прокрутки страницы.
- Сохраняется только текущая ветка: старые варианты отредактированных вопросов и перегенерированных ответов в лог не попадают.
- Размышления и действия Claude (команды, чтение и создание файлов, поиск в интернете, задачи) — свёрнутыми выносками Obsidian, как на сайте, с полным текстом команд, результатов и правок («было / стало»). От размышлений сайт обычно отдаёт только краткие заголовки.
- Заголовки внутри сообщений сдвигаются на два уровня вниз, чтобы в оглавлении Obsidian были видны сами сообщения.
- Служебные сообщения без содержимого пропускаются.

**Файлы**
- Ваши файлы (документы, картинки, архивы, PDF) — в оригинале в `materials/`; в логе ссылка или картинка на месте сообщения.
- Файлы, которые Claude вам отправил, — в `materials/`.
- Рабочие файлы, которые Claude создаёт и правит по ходу работы, — каждой версией в `materials/versions/` (`content v1.js`, `content v2.js`…); ссылка в логе ведёт на версию после этого действия.
- Если файл скачать не удалось — плашка покажет, какой именно.

**Артефакты и диаграммы**
- Артефакты — HTML-страницами, каждая версия отдельным файлом (`Название.html`, `Название v2.html`) с учётом всех правок; работают офлайн. В логе — карточка со ссылкой на файл и на оригинал на claude.ai. Классические артефакты (SVG, код, markdown) — файлами своего типа.
- Диаграммы прямо в чате — самостоятельными `.svg` в тёмной теме сайта, видны в логе картинкой; интерактивные — `.html` с теми же стилями.

**Claude Code в браузере** (`claude.ai/code/session_…`)
- Сессия сохраняется в том же формате: ваши сообщения с вложениями, ответы, размышления, все команды с результатами.
- Сверху — репозиторий, ветка, модель и стоимость сессии по ценам API.
- Скриншоты из результатов команд и картинки из ваших сообщений — в `materials/`.
- Работа субагентов — вложенным блоком внутри вызова.
- Созданные и слитые pull request'ы — видимыми строками со ссылками.
- Под каждым ответом — время хода и точные токены: сколько Claude написал и прочитал (и какая доля прочитана из кэша).
- Сжатие контекста отмечается строкой.

**Токены в обычных чатах**
- Под каждым ответом — оценка объёма: `Ответ ≈ 1,3 тыс. токенов · вся переписка ≈ 13 тыс. токенов + вложения ≈ 10 тыс. токенов`.
- Точных счётчиков сайт не отдаёт, поэтому это оценка по тексту (±20–30%): видимый текст, команды и результаты. Скрытые инструкции и размышления не учитываются.

**Прочее**
- Чат ищется во всех ваших организациях (личной, рабочей).
- Повторный экспорт перезаписывает файлы (лишние файлы от прошлых экспортов не удаляются).

## Установка (Chrome / Edge / Brave)

1. Скачайте код: на странице репозитория **Code → Download ZIP** и распакуйте, или `git clone`.
2. Откройте `chrome://extensions` и включите **«Режим разработчика»** (справа вверху).
3. **«Загрузить распакованное расширение»** → выберите папку с файлом `manifest.json`.
4. Закрепите иконку на панели (значок пазла → булавка).

После обновления кода нажмите ↻ на карточке расширения и обновите вкладку claude.ai (F5).

## Использование

Откройте чат на claude.ai или сессию Claude Code → нажмите иконку расширения. В углу появится плашка с прогрессом и итогом.

**Настройки** — правый клик по иконке (по умолчанию выключены):
- **Сохранять conversation.json** — рядом с `.md` кладутся исходные данные сайта как есть (для Claude Code — `session.json` и `events.json`).
- **Добавлять дату и время к сообщениям** — `## Я · 23.10.2026 09:57`, по местному времени.

**Совет для Obsidian:** длинные логи лучше открывать в режиме чтения (Настройки → Редактор → «Вид по умолчанию для новых вкладок» → «Режим чтения»). В режиме редактирования Obsidian иногда не дорисовывает очень большие выноски.

## Приватность

Расширение обращается только к claude.ai — от вашего имени, с вашей сессией в браузере — и сохраняет файлы на ваш диск. Никуда больше данные не отправляются, никаких сторонних серверов и аналитики нет.

## Ограничения

- Расширение использует внутренний API claude.ai, который не документирован. Если сайт его изменит, экспорт может перестать работать до обновления расширения.
- Файлы, которые Claude создаёт командами (например, архив через `zip`), сайт не хранит — они попадают в лог, только если Claude их вам отправил.
